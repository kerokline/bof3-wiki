# Sources

This page lists the external research behind the facts in this wiki, with its terms and the pages it supports. The game's own code and data are the evidence for every layout and name. A source here confirms a fact or gives a lead; it never replaces a check of the game's bytes. Pages cite and summarise these sources and copy none of their text or tables.

"Terms" is what the owner states. "None stated" means the page or repository carries no license, so all rights stay with the owner and the source is cited only. A "snapshot" is an [archive.org](https://web.archive.org/) copy of the page when one exists.

## How a fact cites its source

- A layout or name proven by the game's data cites a function as `Name (image@0xADDR)` ([conventions](../conventions.md#images-and-citations)). An external source, if any, confirms it.
- A section that rests on a community source ends with a "Sources" line that links this page.
- A fact that only a community source states is a lead, tagged `[inferred]` ([conventions](../conventions.md#evidence-tags)), until a read of the game's own code or data confirms it.
