# Security policy

Report a vulnerability privately. Open the repository's
[Security tab](https://github.com/raulcorreia7/bof3-wiki/security) and choose "Report a vulnerability".
Do not open a public issue for a vulnerability.

## Scope

This repository holds documentation and the build of the book. A problem in the build workflow or in the published site is in scope. A factual error in a page is not a vulnerability; open an issue for it.

## Supported versions

The latest release and `main`.
